# Reproduce-DeepSeek-R1-Survey
This repository collects various works that reproduce DeepSeek R1, as well as works related to DeepSeek R1 and the DeepSeek series.

Trains Qwen3-32B for multi-turn software engineering through RL on R2E-Gym tasks, using test outcomes as rewards, GRPO++, and filtering of truncated agent trajectories. https://www.together.ai/blog/deepswe https://huggingface.co/agentica-org/DeepSWE-Preview https://github.com/agentica-project/rllm
33. Group-in-Group Policy Optimization for LLM Agent Training (GiGPO). Combines episode-level relative advantages with step-level groups anchored on repeated environment states for fine-grained credit assignment without a critic or extra rollouts. https://arxiv.org/abs/2505.10978 https://github.com/langfengQ/verl-agent
34. ReTool: Reinforcement Learning for Strategic Tool Use in LLMs. Combines code-augmented cold-start fine-tuning with outcome-reward RL, interleaving natural-language reasoning and real-time code execution to learn when and how to invoke a code interpreter. https://arxiv.org/abs/2504.11536 https://github.com/ReTool-RL/ReTool
35. MiniMax-M1: Scaling Test-Time Compute Efficiently with Lightning Attention. Introduces CISPO, which clips detached importance-sampling weights while retaining token gradients, alongside hybrid-attention RL for long-context reasoning, coding, and software-engineering tasks. https://arxiv.org/abs/2506.13585 https://github.com/MiniMax-AI/MiniMax-M1
36. Soft Adaptive Policy Optimization (SAPO). Replaces hard clipping with smooth token-level gates and separate temperatures for positive and negative advantages; studies mathematical reasoning and Qwen3-VL training. https://arxiv.org/abs/2511.20347
37. Exploration-Preserving Policy Optimization (ExPPO). Reshapes GRPO/DAPO response advantages using prompt-relative, length-normalized surprisal and prompt success rate to redistribute credit while preserving reward signs; studies solution coverage and correct-answer diversity. https://arxiv.org/abs/2610.04011 https://github.com/jinhangzhan/ExPPO
38. SofT-GRPO: Surpassing Discrete-Token LLM Reinforcement Learning via Gumbel-Reparameterized Soft-Thinking Policy Optimization. Injects Gumbel noise into soft-token generation and uses reparameterized policy gradients to train reasoning policies in continuous concept space. https://arxiv.org/abs/2511.06411 https://github.com/zz1358m/SofT-GRPO-master
39. Gibbs-Gap Policy Optimization for Off-Policy RL with Verifiable Rewards (GGPO). Optimizes a group log-mean-exp contrast of KL-adjusted rewards on off-policy responses, with periodic reference refresh and no learner-to-behavior importance weights. https://arxiv.org/abs/2610.20814 https://github.com/thunderous77/GGPO
40. Agent-Reflex: Teaching Language Agents to Act Reflectively. Mines reflection skills from matched success-failure trajectories with perturbed tool feedback, then combines reflective SFT with agentic RL and skill-guided on-policy distillation for failure recovery. https://arxiv.org/abs/2610.17953 https://github.com/RUC-NLPIR/Agent-Reflex
41. Rollout-Time Intervention: Unlocking Agentic Reinforcement Learning Beyond Policy Limits. Repairs all-failed rollout groups using evaluation rubrics and policy-model self-intervention, then applies perplexity filtering and token reweighting to learn from the corrected trajectories. https://arxiv.org/abs/2610.13438 https://github.com/Alibaba-NLP/qqr
42. Long-Horizon RL Needs Muon. Studies a single-rollout asynchronous recipe combining Muon updates for hidden matrices, token-averaged policy loss, truncated importance sampling, and length and tool-error penalties for repository-level issue resolution. https://arxiv.org/abs/2610.20256
43. Enabling Token-wise Importance Sampling in Off-Policy RLVR with Proximal KL Regularization. Separates the proximal reference from rollout behavior and combines token-wise importance correction with bounded future KL credit for learning from reused responses and stale rollouts. https://arxiv.org/abs/2610.18738
44. A Stronger Teacher Within: Strengthening MoE Models via On-Policy Bidirectional Distillation (MoEvolve). Expands the number of active experts, restores expert cooperation through on-policy distillation, strengthens the expanded model with RLVR, and distills its capabilities back to the original expert activation budget. https://arxiv.org/abs/2610.23185
45. Self-Evolving Coding Agents via Harness-Policy Optimization (Self-HPO). Alternates policy-proposed edits to prompts and runtime logic with RL under the selected harness, using unsolved training tasks to refresh the next harness-search set. https://arxiv.org/abs/2610.22791 https://github.com/MSR-Orchard/Self-HPO https://huggingface.co/self-hpo/Self-HPO-Qwen3.5-35B-A3B
46. ReTerm: Recovery Training for Self-Improving Terminal Agents. Uses recovery demonstrations for SFT, then branches independent rollouts from saved failure states and jointly optimizes ordinary-task and recovery groups with GRPO and verifier rewards. https://arxiv.org/abs/2610.18484 https://github.com/twothsnd/ReTerm https://huggingface.co/datasets/twothsnd/ReTerm-10K
47. Conformal Prediction-Enabled Sequence-level Policy Optimization for Reasoning Language Models (CSPO). Calibrates sequence-level clipping bounds from quantiles of recent training scores, adapting the GSPO-style objective to changes in the policy's score distribution. https://arxiv.org/abs/2610.25092
48. EliteReplay: Preserving Diverse Solutions in RL Post-Training via Quality-Diversity Search. Builds a fixed archive of correct solutions with MAP-Elites using the base model, then combines GRPO with supervised archive replay to retain diverse solution strategies; evaluated on text-to-SQL. https://arxiv.org/abs/2610.22290 https://github.com/skai-research/EliteReplay
49. Mosaic: Multi-Session Agentic Reinforcement Learning. Trains trajectories spanning context compaction or subagent forks, combining outcome-conditioned session-count advantages with session-level shaping from changes in reference-answer likelihood. https://arxiv.org/abs/2610.22174 https://github.com/LARK-AI-Lab/Mosaic
50. Learning Self-Orchestration in Decentralized Agent Swarms. Market-based post-training (MPT) learns agent actions and participation bids together; bids select the next actor and distribute task rewards, while counterfactual rollouts provide preferences for bidding updates. https://arxiv.org/abs/2610.22322 https://github.com/Embodied-Minds-Lab/MPT
51. Self-Credit: Credit Assignment for Long-Horizon Agentic RL via Intra-group Rescaling. Uses cited turns in policy-generated compaction summaries as credit signals, compares matching cited actions across successful and failed rollouts, and rescales turn advantages for long-horizon agent training. https://arxiv.org/abs/2610.28388
52. Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition. Combines multi-domain SFT, outcome-based RL, and multi-teacher on-policy distillation to train a 35B MoE agent for parallel subagent coordination and in-trajectory evidence review across search, coding, and scientific tasks. https://arxiv.org/abs/2610.28578 https://huggingface.co/InternScience/Sage-A1.5
53. EPIC: Rethinking Trust Regions for Autoregressive LLM Policies via Exact-KL Prefix Importance-Ratio Clipping. Calibrates clipping of length-normalized prefix likelihood ratios using a reverse-KL coordinate, while passing gradients through the current token for off-policy autoregressive RL. https://arxiv.org/abs/2610.29999 https://github.com/LiChengxi666/EPIC
54. CORD: Conflict-Aware Optimization for Joint RL and Distillation in Agents. Uses directional gradient projection to combine GRPO and privileged self-distillation, allowing either objective to be protected and applying projection after mini-batch accumulation. https://arxiv.org/abs/2610.29965 https://github.com/LvAoAo/CORD-release
55. Flat-RLVR: Sharpness-Aware Reinforcement Learning with Verifiable Rewards for Reasoning Capacity in LLMs. Applies periodic sharpness-aware updates during GRPO-style post-training to address distribution sharpening, studying solution coverage and single-attempt accuracy on mathematics and code. https://arxiv.org/abs/2610.29281
56. ReAPO: Retry-Aware Policy Optimization for Efficient Exploration in LLM Reasoning. Generates verifier-triggered retries conditioned on failed attempts and computes relative advantages across all attempts, assigning each advantage only to its own response tokens so successful retries do not reinforce preceding failures. https://arxiv.org/abs/2610.28770 https://github.com/Nghi-Dao/ReAPO
57. One Act, Many Masks: Effect-Marginal Policy Optimization for Long-Horizon Agents (EMPO). Shares averaged, length-normalized policy ratios among locally comparable responses with the same executable effect, preserving each response's advantage and supporting GRPO or GiGPO without extra rollouts. https://arxiv.org/abs/2610.29427
58. BIRD-RL: Scaling Agentic Reinforcement Learning over Stateful Data-Centric Environments. Progresses from reasoning and tool-use imitation to single-turn and interactive GRPO with SQL test rewards, using trajectory-bound database replicas and lazy reset for persistent, isolated multi-turn rollouts. https://arxiv.org/abs/2610.29426 https://github.com/bird-bench/BIRD-RL
59. Harness Scaling for Generalizable Agentic Reinforcement Learning. Trains policies across a compact, pairwise-balanced set of prompt, tool, observation, context, and workflow configurations, pairing each task with nearby harnesses to improve cross-harness generalization under PPO or GRPO. https://arxiv.org/abs/2610.29458
60. GIFT: Gradient Informed Filtering for Distillation Augmented Reasoning RL. Ranks distillation tokens by alignment and orthogonal residual relative to GRPO logit gradients, then anneals the selected-token budget to zero while keeping retained-token loss weights fixed. https://arxiv.org/abs/2610.30796 https://github.com/lilifree/GIFT
61. MOER: Mix-Policy Optimization under Expert Prefix Guidance with Selective Rollback. Anneals expert reasoning prefixes, replaces failed guided completions with available expert traces, and combines clipped on-policy GRPO with trust-region supervision of both guided prefixes and completions. https://arxiv.org/abs/2610.30873 https://github.com/CityU-MLO/MOER
62. ReflectPO: Reflection-Guided Policy Optimization for Long-Horizon LLM Agents. Resumes saved environment states using guide-model hints from contrasting branches and repeated interaction loops, then combines tree-based action advantages with paired recovery gains while removing hints from policy-update contexts. https://arxiv.org/abs/2610.30933
63. Same Luck, Different Choice: Twin-World Credit Assignment for Agentic Reinforcement Learning (TWICE). Reuses turn- and line-indexed Gumbel noise in counterfactual continuations and uses paired outcome differences for turn-level credit, allocating branch rollouts by predicted outcome disagreement and token cost. https://arxiv.org/abs/2610.31544
64. Training Small Language Models for Transferable Tool Selection. Uses teacher SFT followed by separate GRPO rewards for instruction decomposition and single-tool selection in a Plan–Retrieve–Select workflow, studying transfer across tool corpora and retrieval backends. https://arxiv.org/abs/2610.31483
65. Avalon-M1: Reinforcement Learning from Collective Rewards (RLCR). Jointly trains a shared policy for a CEO and specialist agents using a collective advantage over sampled agent tokens, message-board coordination, and curricula over rollout horizons, environments, and tasks; studies communication and parallel execution with Avalon-M1-Mini. Paper: https://www.gr.inc/avalonm1.pdf Project: https://www.gr.inc/releases/avalon-m1
66. Self-Assessment Reinforcement Learning for Search-State Awareness in Retrieval-Augmented Large Language Models (SARL). Uses the same policy to assess completed search trajectories in a separate context and revise incomplete ones, combining correctness-transition rewards with a penalty for repeated assessments during GRPO training; inference omits the assessment phase. https://arxiv.org/abs/2610.30435
67. RIPPLE: Recovery Internalization through Process-Level Policy Learning and Effect-Aware Credit for Long-Horizon Agentic Coding. Uses recovery SFT from a teacher restricted to trajectory prefixes, then gates positive and negative GRPO advantages separately for reflection triggers, diagnoses, and corrective actions using local validity signals and attributed test transitions. https://arxiv.org/abs/2610.31276
68. S3AC: Stabilized, Selective, and Scalable Actor–Critic for LLM Reasoning. Uses critic pretraining across policies of different strengths, small value-head initialization, and relaxed critic gradient clipping with CISPO and length-adaptive GAE. DAPS combines predicted success and outcome history to select prompts before rollout. https://arxiv.org/abs/2610.35518
69. DTCA: Denoising Token Credit Assignment for Reinforcement Learning in Diffusion Language Models. Aggregates offline denoising-confidence gains by part of speech, uses these weights to select training timesteps and redistribute group advantages across target tokens, and balances estimated entropy flows for mathematical-reasoning RL. https://arxiv.org/abs/2610.35201 https://github.com/ZJU-OmniAI/DTCA
70. MiRL: Error-Targeted Reinforcement Learning for Correcting Terminal Agent Misbehaviors. Profiles recurring terminal-agent errors, replays reproducible misbehavior prefixes to reconstruct training states, and gates task-test rewards on judge-assessed avoidance of the targeted error in the initial continuation steps. https://arxiv.org/abs/2610.35697 https://github.com/runchu-tian/MiRL
71. MemComposer: Learning to Assemble Memories for LLM Agents via Reinforcement Learning. Trains a memory assembler with GRPO-based ExPO to select and order retrieved experiences, using repeated full-task success rates with selection-size and format penalties while keeping the executor, retriever, and memory bank fixed. https://arxiv.org/abs/2610.21091 https://github.com/Makr-Xie/MemComposer
72. SetGRPO: Calibrating Grader-Induced Policy Optimization. Calibrates joint uncertainty sets over normalized group advantages, uses response-gradient geometry to recover locally consistent updates, and selects a group-acceptance threshold on independent risk-calibration data for rubric-based GRPO. https://arxiv.org/abs/2610.36807
73. When All Rollouts Fail: Policy-Compatible Joint Decoding for Hard-Problem Reasoning (PICO). Intersects student and privileged-teacher token supports under a retained-probability constraint; when all student rollouts fail, a successful joint rollout replaces one failure for mixed-behavior training with token importance correction. https://arxiv.org/abs/2610.36849
74. Guided-RLVR: Guided Exploration in Reinforcement Learning with Verifiable Rewards. Jointly trains a controller and reasoning policy, boosting steering-token logits at high-entropy sentence boundaries during rollout and adding a conditional answer log-perplexity bonus; policy updates use unboosted probabilities. https://arxiv.org/abs/2610.37041
75. Trajectory-Aware Policy Optimization: Closing the State Distribution Gap in Long-Horizon LLM RL (TAPO). Approximates prefix-product importance correction with detached geometric-mean ratios, retains current-token policy gradients, and tightens clipping bounds with prefix length for reasoning RL. https://arxiv.org/abs/2610.13020
76. Efficient Token-Level Policy Optimization for Masked Diffusion Models via Velocity Alignment (LFPO). Uses verifier-scored terminal completions to construct detached pull and push cross-entropy targets at visited masked states, combining block-wise timestep updates with an EMA reference without estimating sequence likelihoods. https://arxiv.org/abs/2603.01563
77. Action-Value Calibration via Continuation Sharing for Long-Horizon Agentic Reinforcement Learning (ConCal). Matches same-task visits by incoming state-action-state transitions, blends shared continuation evidence with individual visit estimates, and recursively calibrates GiGPO action values without additional rollouts. https://arxiv.org/abs/2610.37195 https://github.com/Yingjian-Chen/ConCal
78. CoHARL: Co-Evolving Agent Policies and Executable Harnesses with Reinforcement Learning. Trains a shared policy with group-relative updates across an evolving harness population; a proposer revises harness code from current execution traces and historical accuracy-cost trade-offs. https://arxiv.org/abs/2610.36469
79. BoT-GRPO: Efficient Process-Reward RL for Reasoning via Bag-of-Token Aggregation. Normalizes combined outcome and token-level auxiliary rewards using inverse sequence-length weights across each rollout group, assigning per-token advantages without a learned critic; studies process-reward construction for code generation and mathematical reasoning. https://arxiv.org/abs/2610.09804
80. TeamGym: A Gym for Team Decision-Making by AI Agents with Distributed Information. Controls how pivotal evidence is distributed across participants and trains communication, speaker-selection, and decision policies with GRPO using an LLM-judged final-decision reward. Code is forthcoming. https://arxiv.org/abs/2610.37571
81. Training Foundation Models with a Single Algorithm. Expresses MaxRL and related reward objectives as likelihood fitting to generated target distributions, combining them with pretraining, midtraining, and SFT data through a shared weighted loss and asynchronous data buffer; studies how mixtures and compute schedules affect reasoning, coverage, and retention. Paper: https://arxiv.org/abs/2610.40564 Code: https://github.com/yudasong/unified-training Project: https://yudasong.github.io/unified-training/ Starting checkpoints: https://huggingface.co/sfanm/unified-training
82. SCARL: Sequence Confidence-Aligned Reinforcement Learning. Uses behavior-policy sequence log-likelihoods to construct response weights normalized within advantage-sign classes, emphasizing low-confidence positive-advantage responses and high-confidence negative-advantage responses without changing advantage signs. Paper: https://arxiv.org/abs/2610.40407 Code: https://github.com/kezhh163/scarl
83. PIVOT: Progressive Intervention via Online Teacher Correction. Inserts teacher correction segments after student-generated prefixes, resumes student rollouts, and combines verifier-based GRPO with token-distribution KL supervision restricted to the teacher segments. Paper: https://arxiv.org/abs/2610.40576 Project: https://zhihaoyang30.github.io/PIVOT/
84. Learning to Reason from Reference Samples Alone: Reinforced Adversarial Learning for Modern LLM Post-Training (RAL). Co-trains a generator and an answer-only discriminator on reference answers versus policy outputs, using the discriminator's format-gated reference probability as the generator's RL reward and controlling judge updates to stabilize training. Paper: https://arxiv.org/abs/2610.38851 Code: https://github.com/EdisonScientific/prime-rl-adversarial-paper
85. SCOPE: Selective Critical-Step On-Policy Self-Distillation for Agentic Reinforcement Learning. After supervised error-analysis warm-up, generates step-specific hindsight skills and distills them only at selected errors, combining bounded signed teacher-student updates with success-relative interaction-length rewards. https://arxiv.org/abs/2610.38391 https://github.com/neuqrui/SCOPE https://huggingface.co/collections/neuqrui/scope
86. Don't Lose the Thread: Empowering Long-Horizon LLM Agents with Cognitive Resource Self-Allocation (CORAL). Learns to checkpoint task progress and facts before resetting context, propagating final trajectory rewards across reset-delimited episodes with Multi-episode ARPO after supervised warm-up. https://arxiv.org/abs/2610.40350
87. EpiAgent: Epistemic Self-Play for LLM Agents. Alternates learning explicit beliefs about other agents with belief-conditioned action planning, using subsequent-observation prediction rewards for epistemic updates and entropy-regularized environment rewards for planning through self-play. https://arxiv.org/abs/2610.40227
88. CoSTA: Co-Evolving Self-Play Timeline Agents for Complex Temporal Knowledge Graph Question Answering. Distills coordinator and worker roles into a shared policy, then applies leave-one-out PPO to joint timeline investigations using final-answer rewards shared across both roles. Code and data are forthcoming. https://arxiv.org/abs/2610.38450 https://github.com/haikunhere/CoSTA

6. Absolute Zero: Reinforced Self-play Reasoning with Zero Data. A proposer-solver self-play loop generates and verifies code-reasoning tasks with a code executor, without an external curated training dataset; code, model weights, and logs are released. https://arxiv.org/abs/2505.03335 https://github.com/LeapLabTHU/Absolute-Zero-Reasoner
7. Learning to Reason with Selective Internal Feedback (SIF). Builds internal rewards by comparing ranked token-level self-certainty profiles through window-level and peer-level voting, then filters samples and groups for GRPO updates without reference answers or external verifiers. https://arxiv.org/abs/2610.21392
8. Co-Evolving Acting and Forecasting for Language Agents (CoPE). Adds a multi-step action forecasting objective to GRPO on successful on-policy trajectories, sharing the policy backbone across acting and forecasting while retaining one-action-at-a-time inference. https://arxiv.org/abs/2610.20597 https://github.com/ulab-uiuc/CoPE
9. Explorer-Zero: Improving Self-Play for Long-Horizon Tasks with Decomposable Verifiable Rewards. Alternates proposer-solver training in stateful environments, using the proposer's reached intermediate and final states as verification targets that reward partial task completion without human-authored training tasks. https://arxiv.org/abs/2610.19868
10. Ask to Distill: Learning to Synthesize Data for On-Policy Distillation (A2D). Trains a prompt synthesizer with GRPO using teacher-student disagreement and teacher probability on student candidate tokens, then applies on-policy distillation to the generated question bank without reference answers. https://arxiv.org/abs/2610.27450 https://github.com/GasolSun36/Ask_to_Distill
11. Predictive Bandit Curriculum Reinforcement Learning via Gradient-Based Sample Group Discovery (PGB). Groups training prompts using projected SFT gradients of reference solutions, then predicts each group's learning utility to adapt prompt sampling during GRPO. https://arxiv.org/abs/2610.25704
12. LongZero: Enhancing Long-Context Reasoning in LLMs from Zero Data. Synthesizes structured fictional worlds and question-answer pairs before expanding their evidence into long documents, combines these multi-hop tasks with self-generated retrieval conversations, and trains the model with GRPO. https://arxiv.org/abs/2610.30132 https://github.com/zhennan1/LongZero
13. MS-TTRL: Breaking the Frequency Conflict in Multiple-Solution Test-Time Reinforcement Learning. Uses the current policy to verify distinct outcomes, caches accepted, rejected, and uncertain solutions, and applies inverse-frequency reward scaling only to accepted outcomes during GRPO on unlabeled multiple-solution problems. https://arxiv.org/abs/2610.32234 https://github.com/zzx-peter/Multiple-Solution-TTRL
14. Heterogeneous Agent Collaborative Reinforcement Learning (HACRL). HACPO shares verified reasoning rollouts between heterogeneous policies, using capability-calibrated advantages, conservative sequence-level reweighting, and progressively tightened cross-model clipping; each model runs independently at inference. https://arxiv.org/abs/2603.02604 https://github.com/zzx-peter/HACRL-code
15. EnvLunch: The Environment as a Free Lunch for Learning to Interact.
